# CK-DB-UserInvitation

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-DB-UserInvitation.svg)](LICENSE)

Invitations to create a user account: an invitation targets an e-mail address, carries a secret (the token of the
invitation link), an expiration date, the groups the new user joins and the authentication providers it may use.
