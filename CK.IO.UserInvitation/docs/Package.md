The Pocos and the Cris commands of the user invitations: an invitation targets an e-mail address, carries a secret, an
expiration date, the groups the new user joins and the authentication providers it may use.

Main types: `IUserInvitation`, `ICreateUserInvitationCommand`, `IGetUserInvitationBySecretQCommand`. The handlers are in
CK.DB.UserInvitation.

See the [README](https://github.com/signature-opensource/CK-DB-UserInvitation/blob/stable/CK.IO.UserInvitation/README.md).
