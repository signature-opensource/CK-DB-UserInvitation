The database of the user invitations: the tables (`CK.tUserInvitation`, its groups and its authentication providers),
the procedures and the handlers of the commands of CK.IO.UserInvitation. An invitation records the party through which
it is issued (`IssuingPartyId`, set by the server code).

Main types: `Package`, `UserInvitationTable`, `UserInvitationGroupTable`, `UserInvitationAuthProviderTable`.

See the [README](https://github.com/signature-opensource/CK-DB-UserInvitation/blob/stable/CK.DB.UserInvitation/README.md).
